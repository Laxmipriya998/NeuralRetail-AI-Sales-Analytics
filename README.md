# NeuralRetail AI Sales Analytics Platform

## Project Overview

NeuralRetail is an AI-powered retail analytics platform built using Python, Machine Learning, FastAPI, and Streamlit. The project helps businesses analyze sales performance, forecast future demand, identify customer churn risk, segment customers using RFM analysis, and monitor inventory trends.

---

## Objectives

- Analyze retail sales data
- Forecast future sales demand
- Identify potential customer churn
- Segment customers using RFM analysis
- Generate inventory insights
- Visualize business KPIs through an interactive dashboard

---

- Online Retail II Dataset
