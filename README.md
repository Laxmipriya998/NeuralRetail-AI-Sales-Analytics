# NeuralRetail AI: Retail Sales Intelligence Analytics Platform  

## Project Introduction 

NeuralRetail AI is a comprehensive retail analytics platform created for making business decisions through business intelligence techniques and machine learning. 

The platform provides analysis of previous transactions in order to create useful insights that concern such areas as sales forecasting, customer behavior, optimal inventory levels, and churn prediction. 

The software integrates all data analytics, machine learning, APIs, and interactive visualization into one system of business intelligence. 
----------------------------------------------

## Dataset 

Name of the Dataset: Online Retail II Dataset 

Features used in the analysis: 

-Invoice Information 
-Product Description 
-Customer Information 
-Quantity Ordered 
-Unit Price 
-Country 
-Transaction Date
